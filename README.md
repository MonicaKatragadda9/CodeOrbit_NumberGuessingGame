# CodeOrbit Tech - Number Guessing Game

## Project Description
The Number Guessing Game is a beginner-friendly Python program developed as part of the CodeOrbit Tech Python Programming Internship. The computer generates a random number, and the user tries to guess it.

## Features
- Generates a random number between 1 and 100
- Provides "Too high" and "Too low" hints
- Counts the number of attempts
- Handles invalid user input
- Allows multiple rounds of play

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run the command:

```bash
python number_guessing_game.py
```

On Windows, you can also use `py number_guessing_game.py`.

## Learning Outcomes
This project demonstrates random number generation, variables, loops, conditional statements, functions, user input, and exception handling.
